# 📊 Excel Sales & Customer Analytics Project

## 📌 Project Overview

This project is an **Excel-based data analytics project** focused on analyzing sales, customers, products, sales representatives, and regional performance.

The objective was to take raw business data and use Excel's analytical capabilities to answer practical business questions, identify data-quality issues, and generate meaningful insights for decision-making.

The project demonstrates hands-on skills in **Excel formulas, data cleaning, conditional analysis, pivot-style analysis, ranking, and business reporting**.

---

## 🎯 Project Objectives

The main objectives of this project were to:

* Analyze customer and product information
* Perform lookup operations across datasets
* Identify and diagnose data-quality problems
* Calculate sales and revenue metrics
* Analyze regional and category performance
* Compare sales representatives
* Perform ranking and top-N analysis
* Calculate running totals and cumulative performance
* Extract actionable business insights from raw data

## 📂 Project Structure

The workbook contains multiple sections covering different analytical tasks:

### Q1 — Lookup Functions

Used lookup functions to retrieve information such as:

* Customer details
* Product information
* Sales representatives
* Regions
* Customer segments

This section demonstrates the ability to connect information across multiple Excel tables.

---

### Q2 — Data Cleaning & Quality Diagnostics

Analyzed the dataset for common data-quality problems, including:

* Duplicate records
* Whitespace inconsistencies
* City-name inconsistencies
* Broken customer references
* Orders involving discontinued products
* Suspicious cancelled orders

This section highlights the importance of data quality before performing analysis.

---

### Q3 — Conditional Aggregation

Used conditional aggregation formulas to calculate business metrics such as:

* Regional revenue
* Quarterly sales
* Average order values
* High-discount orders
* Top-performing segments
* Category-level performance

Functions such as `SUMIFS`, `COUNTIFS`, and `AVERAGEIFS` were used extensively.

---

### Q4 — Pivot Analysis

Performed multidimensional analysis using pivot-style calculations.

The analysis covered:

* Region vs. category performance
* Monthly sales
* Quarterly revenue
* Category contribution
* Sales representative performance
* Profit margin analysis

This helped identify patterns across different business dimensions.

---

### Q5 — Advanced Analysis

The final section focused on advanced analytical techniques including:

* Sales representative ranking
* Running/cumulative totals
* Top-performing products
* Top-N representatives
* Highest-value transactions
* Performance comparisons

These techniques demonstrate how Excel can be used for more advanced business analytics.

## 📈 Key Insights

These findings demonstrate how raw transactional data can be transformed into useful business insights.
